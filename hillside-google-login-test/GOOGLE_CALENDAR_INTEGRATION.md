# Google Calendar 正式串接規格（尚未啟用）

此 ZIP 是純前端離線原型，不能安全存放 Google API 憑證，也不會真的新增、更新或刪除 Google 日曆活動。

正式部署須：
1. 由山居學習中心管理員確認既有 Google 日曆 ID、存取權限與日曆公開範圍。
2. 建置安全後端與 Google Calendar API 授權（例如 Workspace 管理下的適當服務帳號授權或 OAuth）。不要在前端寫入密鑰。
3. 僅在後端完成核准及防撞期交易後新增 event，保存 calendarId/eventId/同步狀態。
4. 管理員修改已核准預約時更新同一 event；取消時刪除或取消該 event；待審核、拒絕、補件不建立 event。
5. 建置重試、去重與失敗告警；同步失敗不得偽稱成功，且不應重複新增。
6. 若既有日曆可公開查看，活動標題只顯示「場地｜已借用」，私人活動內容與申請人資料不得同步到公開欄位。
7. 使用 Asia/Taipei 時區，確認校方資訊安全與個資政策。
